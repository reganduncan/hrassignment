HR Assignment Website

This website was created as part of my Information Systems Development and Management assignment. It presents key information in a clear and accessible way, using simple HTML and CSS.

What the website includes

Homepage (index.html)
  Introduces the purpose of the site and provides navigation to other pages.

About Page (about.html)
  Explains the background and context of the HR assignment.

Help/Support Page (help.html) 
  Offers guidance or additional information related to the assignment.

Stylesheet (styles.css)
  Contains the design and layout styling used across all pages.

Purpose of the Website

The aim of this website is to demonstrate:
- Basic web development skills  
- Clear organisation of content  
- Ability to structure and present HR-related information  
- Use of GitHub Pages for hosting a simple website
